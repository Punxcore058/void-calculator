Phone pairing

Open PINX app

Open the Wi-Fi pairing link from the PINX app, enter PIN 123456, and keep both phones on the same Wi-Fi network.

Bluetooth pairing is available on supported Android browsers. Enter the same six-digit PIN, 123456. Stop Wi-Fi pairing before switching modes.

iPhone setup and install (tap ± three times)

On iPhone, open this page in Safari, tap Share, then Add to Home Screen and confirm Add. iOS requires this confirmation; the app cannot install itself. On Android or desktop, use your browser menu to install PINX or add it to your Home Screen.

To connect on iPhone, start Wi-Fi pairing in the PINX Android app, open its pairing link or QR code, then enter 123456. The link serves the calculator from PINX on the local network. iPhone Safari does not support Web Bluetooth, so use Wi-Fi pairing.

The GitHub Pages copy cannot pair directly with a local HTTP device from iPhone Safari; use PINX's local pairing link. The calculator remains available offline.

After the first successful load, the calculator interface and its app icons are cached for offline access. Phone pairing still requires a working connection to PINX on the same Wi-Fi network or a supported Bluetooth browser.

Reveal

For a birthday reveal, enter MMDDYYYY. Results show the date, age, and zodiac sign. Celebrity matches are omitted because this app has no verified celebrity birthday data.
